# resume
My resume, largely sourced and inspired from [Awesome CV](https://github.com/posquit0/Awesome-CV).

View the [PDF](https://raw.githubusercontent.com/hcourt/resume/master/resume.pdf).

## Quick Start

1. Get a TeX distribution: https://www.latex-project.org/get/

    This repo uses XeTex, a flavor of TeX, and XeLaTeX, the XeTeX compiler.

2. Install FontAwesome: https://github.com/FortAwesome/Font-Awesome/blob/v3.2.1/font/FontAwesome.otf?raw=true

3. To compile:

```
> xelatex resume.tex
```

4. To view:

```
> open resume.pdf
```
